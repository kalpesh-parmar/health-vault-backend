<objective>
Audit the 10-step chat lifecycle in `chat.service.js`, standardize language normalization in `commonUtils.js`, and integrate early auxiliary query translation so downstream processing operates with normalized English while preserving user native language.

Purpose: Downstream intent routing, medical entity extraction, and vector searches fail when non-English questions (Hindi, Gujarati, Marathi, Tamil) are passed without translation. Generating `ctx.englishQuestion` early solves this without compromising direct native response generation.
Output: Standardized language normalization, early translation gateway in `chat.service.js`, and automated unit test suite.
</objective>
