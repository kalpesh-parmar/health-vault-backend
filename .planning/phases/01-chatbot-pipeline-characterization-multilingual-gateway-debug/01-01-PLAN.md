<objective>
Implement early query translation in the chatbot pipeline so that non-English questions (Hindi, Gujarati, Marathi, Tamil) are translated early into `ctx.englishQuestion` for downstream intent classification, keyword matching, and context building, while preserving the raw input `ctx.question` and detected language for final response delivery.
</objective>

<execution_context>
@src/utils/commonUtils.js
@src/services/ai/chat/chat.service.js
@src/services/ai/clients/aiClient.service.js
</execution_context>

<context>
Currently, user questions in Indian languages (Hindi, Gujarati, Marathi, Tamil) fail English keyword matching in `_tryIntercepts` and `ragContext.service.js` because downstream regex and dictionary lookups operate on the raw non-English text.
By translating non-English queries early in `_resolveQuestion()`:
- `ctx.englishQuestion` becomes the canonical text for downstream intent classification and keyword detection.
- `ctx.retrievalQuery` and `ctx.cleanQuestion` use `ctx.englishQuestion`.
- `ctx.question` remains untouched for user-facing chat session history.
- `ctx.detectedLanguage` is preserved for prompt localization and final response translation.
</context>

<task>
<name>Task 1: Standardize Language Normalization in commonUtils.js</name>
<action>
Ensure `normalizeLanguage(lang)` in `src/utils/commonUtils.js` robustly handles:
- English: `en`, `eng`, `english` -> `english`
- Hindi: `hi`, `hin`, `hindi` -> `hindi`
- Gujarati: `gu`, `guj`, `gujarati` -> `gujarati`
- Marathi: `mr`, `mar`, `marathi` -> `marathi`
- Tamil: `ta`, `tam`, `tamil` -> `tamil`
Provide ISO2 helper `toLanguageCode(lang)` if needed for translation services.
</action>

<task>
<name>Task 2: Integrate Early Translation Gateway in chat.service.js</name>
<action>
1. In `chat.service.js:_resolveLanguage(ctx)`:
   - Identify language using `aiClient.detectLanguage` or script heuristics.
   - Set `ctx.detectedLanguage`.
2. In `chat.service.js:_resolveQuestion(ctx)`:
   - If `ctx.detectedLanguage` is non-English (`hindi`, `gujarati`, `marathi`, `tamil`), call `aiClient.translate(ctx.question, ctx.detectedLanguage, "english")`.
   - Store result in `ctx.englishQuestion`.
   - Set `ctx.retrievalQuery = ctx.englishQuestion || ctx.question`.
   - Set `ctx.cleanQuestion = ctx.retrievalQuery.trim()`.
3. In `_saveAndReturn(ctx)`:
   - Ensure the raw user question (`ctx.question`) is saved to chat history, NOT the translated English question.
   - Ensure the final reply is delivered in `ctx.detectedLanguage` or user preferred language.
</action>
<verification>
Run unit test passing Hindi and Gujarati questions and verify `ctx.englishQuestion` is populated and used for downstream keyword checks.
</verification>
<done>
Non-English queries are translated early to English for processing while user history and response language remain in the user's language.
</done>
</task>
