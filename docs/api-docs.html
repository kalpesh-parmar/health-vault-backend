File Upload

Upload non-document file (e.g. patient profile picture) to GCS

Generic GCS uploader. Medical documents must NOT be uploaded through this endpoint. Use POST /documents/upload for medical documents so they are picked up by the OCR + AI pipeline.

Only uploadType=PATIENT_PROFILE is accepted here. Sending PATIENT_DOCUMENT returns 400.

Authorizations:
bearerAuth
Request Body schema: multipart/form-data
required
file
required
string <binary>

File to upload
uploadType
required
string
Value: "PATIENT_PROFILE"

Only PATIENT_PROFILE is accepted on this endpoint.

Server-Sent Events stream of OCR progress

Subscribe to realtime progress for a previously uploaded file. The connection stays open and emits stage events shaped like OcrProgressEvent. The stream replays the last buffered events on connect, so it is safe to subscribe slightly before or after POST /documents/run-ocr.

bearerAuth
path Parameters

required
string

Enqueue OCR + AI extraction (non-blocking)

Validates the fileKey, creates a document_processing_jobs row, and returns immediately with status=OCR_STARTED. The pipeline runs in the background; subscribe to the SSE channel for live progress, or poll GET /documents/run-ocr-status/:fileKey.
