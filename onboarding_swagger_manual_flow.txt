================================================================================
 Swagger Payload Sequence for Manual Onboarding & Medication Flow (Add, Edit, Add New)
 Endpoint: POST /v1/onboarding/chat
 Header: Authorization: Bearer <YOUR_ACCESS_TOKEN>
================================================================================

--------------------------------------------------------------------------------
1. START ONBOARDING / SELECT LANGUAGE
--------------------------------------------------------------------------------
[Payload]:
{
  "message": "en"
}
[Action Returned]: ASK_UPLOAD_OR_SKIP


--------------------------------------------------------------------------------
2. SELECT MANUAL ENTRY (Skip Document Upload)
--------------------------------------------------------------------------------
[Payload]:
{
  "message": "MANUAL"
}
[Action Returned]: ASK_FIRST_NAME


--------------------------------------------------------------------------------
3. ENTER FIRST NAME
--------------------------------------------------------------------------------
[Payload]:
{
  "message": "John"
}
[Action Returned]: ASK_LAST_NAME


--------------------------------------------------------------------------------
4. ENTER LAST NAME
--------------------------------------------------------------------------------
[Payload]:
{
  "message": "Doe"
}
[Action Returned]: ASK_DOB


--------------------------------------------------------------------------------
5. ENTER DATE OF BIRTH
--------------------------------------------------------------------------------
[Payload]:
{
  "message": "1995-05-15"
}
[Action Returned]: ASK_GENDER


--------------------------------------------------------------------------------
6. ENTER GENDER
--------------------------------------------------------------------------------
[Payload]:
{
  "message": "male"
}
[Action Returned]: RESOLVE_PROFILE_SOURCE (Confirmation card)


--------------------------------------------------------------------------------
7. CONFIRM BASIC PROFILE DETAILS
--------------------------------------------------------------------------------
[Payload]:
{
  "message": "{\"confirmed\": true}"
}
[Action Returned]: ASK_BLOOD_GROUP


--------------------------------------------------------------------------------
8. ENTER OR SKIP BLOOD GROUP
--------------------------------------------------------------------------------
[Payload]:
{
  "message": "O_POSITIVE"
}
[Action Returned]: ASK_ALLERGIES


--------------------------------------------------------------------------------
9. ENTER OR SKIP ALLERGIES
--------------------------------------------------------------------------------
[Payload]:
{
  "message": "SKIP"
}
[Action Returned]: MEDICINE_OPTIONS


================================================================================
 MEDICATION FLOW (ADD, EDIT, ADD ANOTHER & CONFIRM WITHOUT DUPLICATES)
================================================================================

--------------------------------------------------------------------------------
10. SELECT "ADD ANOTHER MEDICINE" FROM MEDICINE_OPTIONS
--------------------------------------------------------------------------------
[Payload]:
{
  "message": "{\"key\": \"ADD\"}"
}
[Action Returned]: ADD_MEDICINE (Form prompt for new medicine)


--------------------------------------------------------------------------------
11. SUBMIT FIRST MEDICINE DETAILS (Paracetamol 500mg)
--------------------------------------------------------------------------------
[Payload]:
{
  "message": "{\"medicine\":{\"name\":\"Paracetamol 500mg\",\"type\":\"TABLET\",\"dose\":{\"count\":1},\"frequency\":\"ONCE\",\"client_med_id\":\"med_101\"}}"
}
[Action Returned]: REVIEW_MEDICINES_LIST (List containing med_101)


--------------------------------------------------------------------------------
12. [EDIT SCENARIO - OPTIONAL]: EDIT FIRST MEDICINE DETAILS
--------------------------------------------------------------------------------
If user wants to edit med_101 details (e.g. change name to Paracetamol 650mg & dose count to 2 & frequency to TWICE):
[Payload]:
{
  "message": "{\"medicine\":{\"name\":\"Paracetamol 650mg\",\"type\":\"TABLET\",\"dose\":{\"count\":2},\"frequency\":\"TWICE\",\"client_med_id\":\"med_101\"}}"
}
[Action Returned]: REVIEW_MEDICINES_LIST (Updated med_101 details in list)


--------------------------------------------------------------------------------
13. CONFIRM MEDICINES IN REVIEW_MEDICINES_LIST
--------------------------------------------------------------------------------
[Payload]:
{
  "message": "{\"selected\": [\"med_101\"]}"
}
[Action Returned]: MEDICINE_OPTIONS
(Note: med_101 is saved to DB in background, tagged with isSaved = true)


--------------------------------------------------------------------------------
14. SELECT "ADD ANOTHER MEDICINE" AGAIN FROM MEDICINE_OPTIONS
--------------------------------------------------------------------------------
[Payload]:
{
  "message": "{\"key\": \"ADD\"}"
}
[Action Returned]: ADD_MEDICINE


--------------------------------------------------------------------------------
15. SUBMIT SECOND MEDICINE DETAILS (Amoxicillin 250mg)
--------------------------------------------------------------------------------
[Payload]:
{
  "message": "{\"medicine\":{\"name\":\"Amoxicillin 250mg\",\"type\":\"CAPSULE\",\"dose\":{\"count\":1},\"frequency\":\"TWICE\",\"client_med_id\":\"med_102\"}}"
}
[Action Returned]: REVIEW_MEDICINES_LIST (List containing BOTH med_101 and med_102)


--------------------------------------------------------------------------------
16. CONFIRM REVIEW_MEDICINES_LIST WITH BOTH MEDICINES CHECKED
--------------------------------------------------------------------------------
[Payload]:
{
  "message": "{\"selected\": [\"med_101\", \"med_102\"]}"
}
[Action Returned]: MEDICINE_OPTIONS
(Note: med_101 is already isSaved = true, so BE skips inserting it again! Only med_102 is inserted into DB)


--------------------------------------------------------------------------------
17. FINISH ONBOARDING & GO TO DASHBOARD
--------------------------------------------------------------------------------
[Payload]:
{
  "message": "{\"key\": \"DASHBOARD\"}"
}
[Action Returned]: REGISTER_USER / COMPLETE ("Thank you! Onboarding is complete.")
================================================================================
